# Quark Saver

`Quark Saver`（夸克网盘转存助手）是一款基于 **Tauri 2 + React 19** 构建的跨平台桌面应用。它把夸克网盘的常用操作集中到一处，支持**多账号管理**、**浏览 / 搜索网盘文件**、**批量转存他人的分享链接**，并在转存后**一键再分享**出去，是整理网盘资源的得力工具。

## 功能概览

- **多账号管理** — 扫码登录或手动粘贴 Cookie 添加夸克账号；Cookie 仅保存在本地（Rust 侧），支持默认账号、重命名、删除与有效性校验。
- **文件浏览与搜索** — 浏览网盘目录结构、分页加载、搜索、删除 / 重命名 / 复制文件。
- **批量转存分享链接** — 粘贴一段包含任意个 `https://pan.quark.cn/s/xxx` 链接的文本，自动识别每个链接，逐条转存到指定账号的指定目录。
- **转存后自动分享** — 可选「转存后自动分享并获取链接」，转存 → 快照对比找出新增文件 → 自动创建分享 → 一键复制所有链接。
- **长任务流水线** — 转存 / 转存并分享以后台进度事件驱动，支持进度条、失败详情、运行中取消、最小化到后台继续执行。
- **主题系统** — 深色 / 浅色 / 跟随系统三种模式，7 种强调色预设。

## 使用说明

### 夸克网盘

进入应用后，通过左上角「夸克网盘」标签页管理网盘。登录夸克账号后即可浏览文件、管理分享链接以及保存资源。

![夸克网盘-文件浏览](/images/quark-saver/file-browser.png)

*夸克网盘文件浏览界面*

![夸克网盘-我的分享](/images/quark-saver/my-shares.png)

*夸克网盘我的分享界面*

**操作步骤：**

1. 在「账号设置」弹窗中扫码登录或粘贴夸克 Cookie 添加账号
2. 选择需要操作的账户
3. 在「文件浏览」标签页中浏览目录和文件
4. 在「我的分享」标签页中查看和管理分享链接

### 批量转存分享链接

转存他人分享的资源到自己的网盘，是 Quark Saver 的核心能力：

![转存分享链接-填写](/images/quark-saver/save-links.png)

*批量转存分享链接弹窗*

**操作步骤：**

1. 点击网盘页右上角的「转存」按钮
2. 粘贴包含若干 `https://pan.quark.cn/s/xxx` 分享链接的文本，程序会自动识别
3. 设置保存间隔（秒）与目标目录
4. （可选）勾选「转存后自动分享并获取链接」
5. 点击「开始转存」，后台自动逐条完成任务

转存完成并自动分享后，会列出新生成的分享链接，支持单个复制或「一键复制所有链接」：

![转存分享链接-已生成](/images/quark-saver/share-generated.png)

*分享链接已生成弹窗*

## 常见问题

**Q: Quark Saver 需要付费吗？**

A: Quark Saver 免费使用，无需授权激活。

**Q: 夸克 Cookie 会保存在哪里？**

A: Cookie 仅保存在本地（Rust 侧持久化到 `accounts.json`），前端只持有不透明的账号 ID，不会上传到任何服务器。

**Q: 支持 macOS / Linux 吗？**

A: 目前仅提供 Windows（x64）版本，后续会考虑提供更多平台。
